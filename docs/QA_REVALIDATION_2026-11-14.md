## 발견한 문제와 최소 수정

1. **Windows 새 체크아웃의 해시 검사 실패:** `core.autocrlf=true`가 해시 고정된 Mojang `LICENSE.md`의 LF를 CRLF로 바꾸어 222바이트를 224바이트로 만들었습니다. 첫 회귀 결과는 203/204이며 소스 검증도 실패했습니다. `.gitattributes`에서 이 파일만 `-text`로 지정하고 소스 ZIP에도 `.gitattributes`를 포함했습니다. 별도 신규 Windows 방식 체크아웃에서 원본 SHA-256과 204/204 통과를 확인했습니다. 테스트 기대치나 라이선스 내용은 바꾸지 않았습니다.
2. **공개 전체 ZIP의 해시 파일명 불일치:** 기존 `Manhunt_Night_v1.5.1_FullFiles.zip.sha256` 내부는 `Manhunt_Night_v1.5.1_전체파일.zip`을 가리킵니다. 해시 값 자체는 실제 FullFiles.zip과 일치합니다. 앞으로 생성하는 전체 ZIP 이름을 공개 이름인 `FullFiles.zip`으로 맞추고 빌드 안내를 수정했습니다. 기존 자산은 보존하며 공개 파일명을 사용한 별도 `SHA256SUMS_GITHUB_ASSETS_2026-11-14.txt`를 보완 자료로 제공합니다.

게임 로직, BP/RP, 기존 204개 테스트 및 저장 형식은 변경하지 않았습니다.
