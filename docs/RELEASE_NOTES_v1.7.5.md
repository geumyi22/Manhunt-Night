# Manhunt Night v1.7.5 — Stable

**2026-11-18 (KST) 승인.** v1.6.0 Stable을 보존하면서 다른 Bedrock 월드 호환성을 높인 정식 릴리스입니다.

## 변경 사항
- 모든 새 시드에서 기존 21×21 파랑·빨강 공중 로비를 자동 생성하고 기존 지형을 보호하도록 위치·높이를 검사합니다.
- **Y≈100 공중 출발 수정:** 경기 시작 전 지면·안전한 발판·머리 공간을 검사하고 기존에 잘못 저장된 시작 위치도 보정합니다. 러너/헌터 출발 및 리스폰에 적용합니다. 안전한 지면이 없으면 게임 시작을 거절합니다.
- 다른 시드의 오버월드·네더 경계는 맵 시작 위치를 기준으로 동작합니다.
- 네더 요새 자동 발견은 탐험 지역의 자연 스폰 위더 스켈레톤과 요새 벽돌을 함께 확인한 경우 해당 근처의 **추정 좌표**를 저장합니다. 40분 경과나 헌터 선진입 시 러너에게만 알려주며, 호스트가 검증한 수동 좌표가 우선합니다.
- 2~8인 경기, 추적기 무작위 공동 제작(20분 공개·40분 지급), 32방향 나침반·러너 부활·헌터 소집·수신기·전적 등 기존 기능을 보존합니다.

## 검증
- 사용자 실기 신규·변경 기능 **14/14 통과**. 최초 13개 통과와 Y≈100 출발 수정 후 재검증 결과는 사용자 보고로 기록합니다.
- GitHub Actions에서 **249/249 회귀 테스트**, 정식 Script API 타입·JS 구문·아이템/팩 검사, 배포 ZIP CRC·SHA-256 및 기존 월드 DB 바이트 동일성 검사를 수행했습니다.
- 이전 v1.6.0 원본 세계와 해당 릴리스 자산·QA 기록은 변경하지 않았습니다.

## 다운로드 선택
- `Manhunt_Night_v1.7.5.mcworld`: 기존 전용 맨헌트 월드 포함
- `Manhunt_Night_v1.7.5.mcaddon`: 다른 월드 복사본에 행동·리소스 팩 적용
- `Manhunt_Night_Source_v1.7.5.zip`: 소스·테스트·문서
- `Manhunt_Night_v1.7.5_FullFiles.zip`: 전체 패키지
- `SHA256SUMS.txt`, `Manhunt_Night_v1.7.5_FullFiles.zip.sha256`, `BUILD_MANIFEST.json`, `PACKAGE_CHECKS.json`: 검증 정보

## 알려진 한계
- 요새 자동 발견은 미탐험 구조물 검색이 아니라 실제 탐험 중 발견한 근거에 따른 추정입니다. 스폰되지 않는 경우, 커스텀 구조물, 특수 애드온 환경에서는 실패하거나 오인할 수 있습니다.
- 실제 8인 규모의 성능·FPS·게임별 네트워크 수치는 별도 실측이 없으므로 보장하지 않습니다.
- 기존 월드는 반드시 백업하고 새 버전의 행동·리소스 팩을 중복 적용하지 마세요. 경기 시작 시 아이템/경험치는 초기화되며, 경기 초기화가 지형·엔더 드래곤을 복원하지는 않습니다.
