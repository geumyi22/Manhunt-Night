# Manhunt Night v1.7.5 — 외부 맵 호환성 기능

> Pre-release. 다른 시드의 실제 게임 적용은 추가 검증 대상이며 v1.6.0 Stable의 게임 기능을 대체하지 않습니다.

## 비파괴 로비와 세계 경계

- **모든 신규 월드에서 원본 스타일 공중 로비 자동 생성:** 21×21 파란색(러너)·빨간색(헌터) 구역, 중앙 경계, 유리 테두리 및 네 모서리 조명 기둥을 기존과 같은 블록 배치로 건설합니다. 먼저 공간 전체가 비어 있는지 확인하며 장애물이 있을 때는 가까운 X/Z와 Y=304·288·272 후보를 순서대로 시도합니다. 안전한 후보가 없다면 기존 블록을 보호하고 건설을 중단합니다.
- 외부 시드의 팩 최초 로드만으로 플레이어 인벤토리·전역 스폰을 변경하지 않습니다. 원본 전용 시드에서는 기존 생성 정책을 유지합니다. 다만 맨헌트 경기 시작 시 인벤토리·장비·경험치 초기화와 게임 룰 변경은 그대로 적용됩니다. 저장된 기존 공중 로비는 유지하고, 이전 시험 버전의 좌표 전용 로비는 대기 상태에서 실제 건축형 로비로 전환합니다. `/mh:lobbycreate`는 로비가 없을 때만 재시도하며 `/mh:unstuck`은 이미 있는 로비로 이동합니다.
- 다른 시드: 오버월드 시작점 중심 ±5000블록, 네더에서는 시작 X/Z를 8로 환산한 점 중심 ±625블록. 엔드는 기존 원점 ±5000블록입니다.

## 네더 요새 자동 발견과 좌표 안내

- **자동 발견(신규):** 정식 경기 중 네더에서 자연적으로 스폰된 위더 스켈레톤과 근처의 네더 벽돌 8개 이상을 확인하면 X/Z를 자동 기록합니다. 96블록 내 중복 제거·최대 8곳 저장, 월드 재시작 후에도 유지됩니다. 자연 생성 구조물 여부의 확정 판정은 아니며, 해당 부분은 호스트 수동 좌표 검증이 더 정확합니다.
- **노출 제한:** 자연 발견 즉시 좌표를 채팅에 공개하지 않고, 기존 40분 경과 또는 헌터 선진입 조건에서 **러너에게만** 힌트를 제공합니다. 자동 발견 후보가 여러 개면 러너의 위치에 가까운 것을 선택합니다.
- **관리자 설정:** `④ 월드 / 안내 / 보상 → 네더 요새 자동 발견`은 기본 ON이고 OFF할 수 있습니다. 요새 좌표 미등록·미발견 시 숫자를 만들어 내지 않고 미확인 안내만 표시합니다.
- **수동 대안:** 호스트가 `/locate structure fortress`의 X/Z를 관리자 메뉴에 등록하면 자동 발견 좌표보다 우선합니다.
- **API 제약:** `getGeneratedStructures`는 아직 Pre-release API이며 정식 `CommandResult`는 /locate 좌표를 제공하지 않습니다. 탐사하지 않은 먼 요새의 좌표는 자동 발견으로 보장할 수 없습니다.

## 다른 맵 네더 요새 안내

- 호스트가 /mh:menu → 다른 맵 / 네더 요새 좌표 관리에서 실제 네더 요새 X/Z를 입력하거나 네더의 현재 위치를 등록할 수 있습니다.
- 수동 좌표가 미등록이어도 자동 발견 후보가 있으면 러너에게 발견된 추정 위치를 안내합니다. 기록된 후보도 없으면 다른 시드에 기존 요새 좌표를 잘못 보여주지 않습니다. 40분 경과나 헌터 선진입 조건에 한 번 안내하며 등록 이후 좌표를 알려줍니다.
- 다른 맵의 요새 도착 판정은 등록한 좌표 근처(가로 ±192블록)에서 네더 벽돌을 확인합니다. 플레이어가 지은 벽돌 구조를 자연 요새로 완벽히 판별할 수 없으므로 실제 요새 좌표로 등록해야 합니다.
- Script API는 /locate의 정확한 X/Z를 직접 반환하지 않으므로 미탐험 요새를 정확히 안내하려면 호스트 확인이 필요합니다. 요새 힌트 OFF 시 나머지 기능은 유지됩니다.

## v1.6.0부터 이어지는 게임 기능

## 기본 경기

정식 경기 2~8명, 러너 1명·헌터 1~7명. 8명은 규칙상 상한이며 실제 8인 성능은 미검증입니다. 2인 경기에서는 다른 헌터가 없어 소집서를 소비하지 않으며, 추적기 팀 제작은 한 헌터가 진행합니다. 혼자 연습 가능하며 연습 결과는 정식 전적에 기록하지 않습니다. 러너 지정 또는 매 경기 무작위 선택, 5초 카운트다운, 기본 도주 유예 60초. 경기 시간은 러너가 출발할 때 시작하며 도주 유예를 포함합니다. 카운트다운·일시정지·종료 중에는 흐르지 않습니다. 재접속 대기 시 기본 자동 일시정지. 월드를 다시 열어도 자동 재개하지 않습니다.

참가 헌터가 러너를 죽이거나 러너의 야생 부활 기회가 소진되면 헌터 승리. 러너가 생존한 상태에서 엔더 드래곤이 죽으면 러너 승리. 헌터는 무제한 부활. 비참가자·자기 자신은 참가 헌터 처치로 분류하지 않습니다.

## 러너 추적기

이름 `§a§l러너 추적기§r`. 헌터용이며 러너에게 지급하지 않습니다. 공식 원본 atlas에서 픽셀 변경 없이 분리한 32개 나침반 프레임의 빨간 바늘이 소유자 시선에 대한 목표 방향을 가리킵니다. 이론상 11.25도 단위(양자화 오차 최대 5.625도), 2틱 갱신. 실제 화면은 16픽셀 해상도와 네트워크/틱 지연의 영향을 받습니다. 원본은 중복 모양을 포함하여 실제 고유 그림은 28개입니다. 바닐라의 목표 setter를 사용하는 방식이 아니며 내부 흔들림·보간 동작과 같다고 보장하지 않습니다.

같은 차원: 러너 실시간 위치. 다른 차원: 현재 러너 차원 및 해당 차원을 떠난 마지막 위치로 표시합니다. 좌표를 8배 변환해 현재 위치인 것처럼 표시하지 않습니다. 이 차원 기록이 없으면 정보 없음으로 표시합니다. 헌터 팀원 위치 HUD는 별도 기능입니다.

새 월드 기본은 무작위 제작입니다. 0~20분 비공개·제작 불가, 20분에 헌터에게만 공개, 20~40분 팀 공동 제작, 40분까지 미완성이면 자동 지급. 제작 성공과 자동 지급은 하나의 팀 완료 상태를 공유합니다. 일시정지 시간 제외. 기존 15분 제한은 기존 나침반/HUD 모드에만 적용됩니다.

### 투척 제작 사용법

1. `/mh:trackerrecipe`에서 순서·수량·공유 진행도를 확인합니다.
2. `/mh:craft`로 제작 모드를 켭니다. 20분 이전, 비참가자, 러너, 죽은 플레이어는 켤 수 없습니다.
3. 지정된 재료만 순서대로 Q로 버립니다. 한 개씩 나눠 버려도 됩니다. 한 번에 남은 수량보다 많이 버리면 **전체를 그대로 둡니다**. 잘못된 재료도 소비하지 않습니다.
4. 다른 헌터도 자신의 제작 모드를 켜고 현재 단계에 재료를 보탤 수 있습니다. 팀 공유 9단계를 완료하면 접속 중 헌터에게 1개씩 지급됩니다.
5. 다시 `/mh:craft`를 입력하면 일반 아이템 버리기로 돌아갑니다. 차원 이동·사망·접속 해제·일시정지 시 제작 모드가 해제됩니다.

일반 21종 중 7종 + 어려움 6종 중 2종 = 총 27종 후보에서 9종 선택. 어려운 재료는 각각 기본 6개입니다. [전체 후보·획득 방법·난도](API_RESEARCH_v1.5.md)를 참고하세요.

미접속·인벤토리 부족은 지급 보류, 재접속·빈칸 확보 후 1회 처리. 분실·사망으로 추적기를 잃어도 기본 재지급 없음. 선택 설정으로 팀 완료 후 일반 나침반을 추적기로 변환할 수 있습니다. 아이템 소유권·수량·새 투척인지 불명확하면 소비하지 않습니다. 강제 종료 중 결과가 불명확한 거래는 멈추고 관리자 메뉴의 거래 확인으로 실제 소비/지급 여부를 확인해야 합니다. 확실하지 않으면 보류합니다.

## 러너 패시브·부활

추가 체력 20HP로 기본 하트 두 줄, 포만감 I. 도주 유예 동안 포만감 V·재생 I·느린 낙하 I, 유예 종료 시 임시 효과 제거. 부활하면 체력을 가득 채웁니다.

새 월드 야생 부활 기본 2회. 부활 토템을 사용하면 1회 추가하여 기본 **경기 누적 총 3회**까지 확보합니다. 사용한 기회도 누적 최대에 포함하므로 소진 후 무한 충전되지 않습니다. 제작대 주변 8칸 네더라이트 주괴, 중앙 불사의 토템. 러너만 살아 있는 경기 중 사용, 실패·최대치·헌터·종료 상태에서는 소비하지 않습니다. 아이템 자체는 바닐라 자동 불사 효과가 아닌 우클릭 부활 기회 추가용입니다.

90·60·40·10블록 네 단계 접근 경고: 같은 차원의 가장 가까운 살아 있는 헌터, X/Y/Z 3차원 거리. 러너에게만 메시지와 선택 효과음. 경계 2블록 여유와 구간별 기본 10초 쿨다운. OFF 시 거리 계산 생략.

## 헌터 소집서

종이 형태. 제작대 `종이/엔더 진주/종이`, `엔더 진주/나침반/엔더 진주`, `종이/엔더 진주/종이`로 제작. 시작 시 무료 지급하지 않습니다.

같은 차원에 있는 살아 있는 헌터들을 사용자의 주변으로 이동시킵니다. 다른 차원 헌터는 알림만 받습니다. 같은 차원 러너로부터 사용자·각 도착 지점 모두 **350블록 초과**여야 하며 정확히 350도 금지. 다른 차원의 러너는 거리 제한에서 제외. 기본 팀 공용 쿨다운 300초·경기당 2회. 성공 시 1개 소비, 실패 시 보존.

지면·머리 공간·위험 블록·경계·플레이어 겹침을 모두 먼저 확인합니다. 안전 위치 부족은 취소. 이동 중 오류는 기존 위치로 복구하고 미완료 상태를 기록합니다. 안전 판정은 보수적이어서 계단/알 수 없는 사용자 블록에서 소집이 거절될 수 있습니다. `획득 중지` 설정은 제작 레시피 자체를 동적으로 숨기지는 못하며 사용을 차단합니다.

## 유지되는 월드·수신기 기능

오버월드·엔드 10,000×10,000(X/Z -5000~4999), 네더 1,250×1,250(-625~624). 월드 스폰 반경 0. 러너가 출발 후 40분 동안 네더 요새에 도착하지 않았거나 헌터가 먼저 네더로 들어가면 러너에게만 요새 힌트 1회. 러너 엔드 첫 진입 시 엔더의 눈 32개.

**원본 월드의 고정 요새 지도는 해당 시드 전용입니다.** v1.7.5는 다른 시드에서 이를 사용하지 않고 탐험 중 자동 기록한 추정 좌표 또는 호스트가 등록한 좌표를 사용합니다. 자동 발견이 실패하거나 정확한 좌표가 필요할 때는 수동 등록을 사용하세요. 요새 기능을 꺼도 다른 경기 기능은 유지됩니다.

신호 수신기 제작: 석탄/구리 주괴/철 주괴, 금 주괴/바다의 심장/청금석, 에메랄드/다이아몬드/네더라이트 파편. 러너 우클릭 시 녹색 광선 8초·같은 차원 헌터 카메라 3초, 재사용 30초. 멀리 있거나 벽 뒤에서는 광선이 보이지 않을 수 있습니다.

## 명령어와 초기화

## 오류 후 관리자 복구
