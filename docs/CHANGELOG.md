## v1.5.1 — 2026-11-08

- 공식 원본 나침반 atlas의 32방향 프레임을 그대로 적용. 출처·저작권/EULA 별도 명시, 원본과 RGBA 픽셀 대조.

- 주기 등록 시점에 따라 경계 복귀·신호 광선이 계속 생략되던 나머지 연산 조건을 실행 시각 기준으로 수정.
- 시작 카운트다운을 정확히 100틱으로 처리하고, 경기 중 일시정지·재개 시 다음 초까지 남은 부분 틱을 보존하도록 수정.
- 동시 제작·저장 실패·재접속·중복 지급 경로의 회귀 검사 확장.
- 실제 제작대·사망·차원 이동 시험 결과와 친구용 점검표 추가.
- 기존 v1.5.0 월드·릴리스·설정·전적 형식을 보존. 실제 다중 기기 검증 전까지 Pre-release 유지.
