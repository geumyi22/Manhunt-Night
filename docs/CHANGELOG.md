# 변경 기록

## v1.7.5 — 다른 맵 호환성 및 네더 요새 자동 발견 (2026-11-18 · Pre-release)

- 기존 21×21 공중 로비 자동 생성, 안전한 위치 탐색·실패 시 일부 롤백과 수동 재시도, 기존 지도·경기·설정 보존 기능을 통합.
- 자연 발생 위더 스켈레톤과 주변 네더 벽돌 증거를 확인한 경우에 한해 **탐험한 지역의 요새 위치를 자동 추정·기록**, 최대 8곳·96블록 중복 제거.
- 40분 경과 또는 헌터 네더 선진입 시 러너에게만 자동 발견 위치를 안내하고, 자동 탐지가 없으면 미확인 안내만 제공. 호스트 수동 등록은 자동 후보보다 우선.
- 별도 토글로 자동 발견 비활성화 가능. v1.6.0 Stable 원본과 이전 QA·월드 DB·팩 UUID는 보존.
- 정식 API에서 미탐험 요새의 구조물 좌표 반환은 지원되지 않아 사전 전체 검색을 보장하지 않음. 실제 외부 시드 멀티플레이 검증 완료 전까지 Pre-release.



- 다른 시드에서도 **기존 원본과 같은 공중 로비 자동 생성** 추가(21×21 파란색·빨간색 바닥, 유리·조명 기둥). 빈 공간 사전 검사 후 주변 위치·높이 후보 탐색, 기존 건축물 보호, 실패 시 생성 중단 및 `/mh:lobbycreate` 재시도 지원. 기존 좌표 전용 로비를 안전하게 업그레이드하고, 이미 생성된 로비는 재사용합니다.
- 건축 오류 시 직접 배치한 블록만 되돌리는 롤백 시도와 임시 ticking area 정리. 기존 로비 저장 데이터·기존 플레이 인벤토리를 보호하고 실패 시 재시도 명령 제공.
- 맵 시작 좌표에 따른 오버월드/네더 경계 위치 적용. 엔드는 원점 기준 유지.
- 다른 시드에서 고정된 요새 좌표 오안내 방지. 호스트 수동 좌표 등록 및 요새 도착 조건 추가.
- 기존 v1.6.0 Stable 코드·월드 DB·팩 UUID·QA 원문 보존, 별도 v1.7.0 빌드 및 자동 회귀 검증.
- 실제 다른 시드·다중 기기 검증이 완료되기 전에는 Stable 승격 금지.

## v1.6.0 — 2026-11-14 · Stable

- 정식 경기 인원을 3~4명에서 2~8명으로 확장. 러너 1명과 헌터 1~7명, 1인 연습 유지.
- 시작 검사·메뉴·새 월드 이름에 같은 인원 범위를 표시. 9명 이상이면 기존 상태를 바꾸기 전에 시작 거절.
- 기존 게임 규칙·제작법·아이템·저장 형식·팩 UUID 유지. 기존 월드와 v1.5.1 릴리스 보존.
- 인원 경계, 2인 승패·재접속, 8인 지급·소집의 자동 회귀 검사를 추가. 실제 검증 범위는 QA 보고서 참조.
- 2인에서는 다른 헌터가 없어 소집서를 소비하지 않음.
- 사용자와 친구들의 직접 QA, 실제 2·3인 게임 흐름, 기존 204개를 포함한 212개 회귀·타입·패키지 검사와 CI 결과를 반영하여 Stable 배포 승인.
- 기본 20/40분 LONG과 실제 3인 THREE의 TPS·호스트 메모리 기록을 공개. FPS·게임 네트워크 수치, 실제 8인 규모와 세부 미확인 상황은 알려진 제한으로 유지.
- 게임 코드와 기존 v1.6.0 태그·배포 자산은 보존. 최신 소스·설치 안내·QA·해시는 별도 Stable 묶음으로 제공하며 과거 QA 원문과 해시는 변경하지 않음.
