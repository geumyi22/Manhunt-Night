# 설치 안내 (v1.4.0)

게임을 설치하려면 GitHub Releases에 첨부된 `.mcworld` 파일을 받아 Minecraft Bedrock으로 가져옵니다. 월드에는 애드온이 포함되어 있어 `.mcaddon`을 다시 적용할 필요가 없습니다.

1. 기존 맵은 삭제하지 말고 백업합니다.
2. 새 `.mcworld`를 가져오고 친구 3~4명을 초대합니다.
3. `/mh:menu`로 러너와 게임 설정을 선택합니다.
4. 처음 플레이할 때 설정과 추적 동작을 테스트 월드에서 먼저 확인합니다.

`.mcaddon`은 다른 월드에 적용할 때만 따로 사용합니다.

**주의:** v1.4.0은 자동 테스트를 통과했지만 실제 3~4인 멀티플레이·클라이언트 E2E 검증은 완료되지 않았습니다.
