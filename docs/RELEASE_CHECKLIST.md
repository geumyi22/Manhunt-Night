## 알려진 제한과 추가 확인 범위

- [ ] 실제 FPS·게임별 네트워크 수치 확보 — 현재 미측정
- [ ] 실제 8인 상한/HUD·성능 — 확인된 2·3인 플레이와 별도
- 접근 경계 반복 시 대기, 다른 차원 카메라 비전환, 미접속·만석 지급은 상세 결과가 구체적이지 않은 개별 상황입니다. 이미 확인한 게임 흐름의 재시험을 요구하지 않습니다.
- 중단된 소집 복구는 해당 상황이 생겼을 때의 추가 점검이며, 강제 실패 재현을 새 필수 조건으로 삼지 않습니다.

사용자는 이 확인 범위와 제한을 안내받은 뒤 Stable 출시를 요청했습니다. 미측정 항목을 성공으로 바꾸지 않고 제한을 공개한 상태로 배포합니다.
