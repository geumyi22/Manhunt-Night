# Manhunt Night v1.7.5 Stable — 설치 및 사용

최신 정식 파일: [v1.7.5 Stable Release](https://github.com/geumyi22/Manhunt-Night/releases/tag/v1.7.5). 기존 v1.6.0 Stable·월드 원본은 보존됩니다.

1. **대상 월드를 먼저 복사·백업**합니다. 정식 게임 시작 시 참가자 소지품·장비·경험치가 초기화됩니다.
2. 기존 제공 월드를 사용한다면 `Manhunt_Night_v1.7.5.mcworld`를 가져옵니다. 해당 파일에는 행동 팩·리소스 팩이 포함돼 있어 중복 `.mcaddon` 적용이 필요 없습니다.
3. 다른 시드나 커스텀 맵이라면 월드 **복사본**에 `Manhunt_Night_v1.7.5.mcaddon`을 적용하고 행동·리소스 팩을 모두 활성화합니다. 충돌할 수 있는 다른 맨헌트 애드온은 함께 사용하지 않습니다.
4. `/mh:menu`에 **`Stable v1.7.5 · 지면 출발 보정`** 문구가 나타나는지 확인합니다. 같은 번호의 이전 Preview/RC1 빌드가 남아 있다면 해당 시험 팩을 비활성화하고 Stable 팩으로 교체합니다. 데이터를 보호하려면 월드 자체를 지우지 마세요.
5. 새 맵은 처음 오버월드 입장 시 빈 공간에 기존 파랑/빨강 공중 로비를 생성합니다. 실패 시 안전한 오버월드 위치에서 `/mh:lobbycreate` 재시도. `/mh:unstuck`은 이미 만들어진 로비로 이동합니다.
6. `/mh:menu`에서 러너·헌터를 정하고 경기를 시작합니다. 로비 Y와 실제 경기 출발 Y는 별도로 계산하며, 지면/머리 공간 안전성 검사를 통과하지 못하면 경기 시작을 거절합니다.

## 네더 요새 안내

네더에서 자연 발생 위더 스켈레톤과 근처 요새 벽돌이 감지되면 해당 **추정 위치**를 자동 기록합니다. 기존 40분/헌터 선진입 조건에서 러너에게만 안내하며, 발견하지 못한 경우 거짓 좌표를 출력하지 않습니다. 미탐험 요새까지 자동 검색하지는 않습니다. 네더에서 `/locate structure fortress`로 정확한 좌표를 확인한 뒤 호스트 메뉴에 수동 등록할 수 있습니다. 특수 제작 맵에서는 요새 안내·자동 발견·경계를 끌 수 있습니다.

## 데이터 주의

로비 건설은 월드에 블록을 새로 놓습니다. 점유된 기존 지형을 보호하고 실패 시 롤백을 시도하지만 엔진 중단을 포함한 모든 상황에서 무손실을 보장하지는 않습니다. 경기 초기화로 이미 파괴한 지형·아이템·엔더드래곤은 복원되지 않습니다.
