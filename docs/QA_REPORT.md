# Manhunt Night v1.7.5 — Stable 최종 QA

**실기 검증 승인: 2026-11-18 KST. 신규/변경 항목 14/14 PASS (사용자 보고), 자동 회귀 249/249 PASS.** 기존 v1.6.0 Stable의 2·3인 실기 QA와 원본 데이터는 별도로 보존합니다.

## 사용자 실제 Minecraft 시험

사용자가 v1.7.5 신규/변경 기능의 초기 실기 QA에서 **13개 통과·1개 실패**를 보고했습니다. 실기 통과 13개는 공중 로비 자동 생성/위치 탐색/건축물 보호/재접속, 다른 맵의 오버월드·네더 경계, 네더 요새 자동 발견·미발견 안내·러너 전용 힌트·수동 좌표 우선·기록 보존, 2~3인 짧은 경기와 사용자 관찰상 신규 지연/콘텐츠 로그 오류 없음입니다.

유일한 실패는 경기 출발 지점이 실제 지면이 아닌 Y≈100 공중에 잡히는 문제였습니다. Issue #15로 분리하고 **실제 지면·발판·머리 공간 검사, 저장된 잘못된 출발 좌표 보정, 카운트다운/헌터 출발 전 재확인**을 추가했습니다. 새 RC1 빌드에서 사용자가 `지면 출발 검증 통과, v1.7.5 Stable 승인`이라고 보고하여 **최종 14/14 통과**로 기록합니다. 로그·영상으로 수치를 새로 계측한 것으로 표시하지 않습니다.

## 자동·패키지 검증

- **249/249 자동 회귀 테스트 PASS**, 0 실패·0 건너뜀 (Y≈100 시작값 보정, 안전 지면 미발견 시 인벤토리/라운드 무변경 거절, 지형 변경 시 재검사 및 일시정지 포함).
- JavaScript/MJS 구문·공식 `@minecraft/server` 2.11.0, `@minecraft/server-ui` 2.3.0 타입 검사, 아이템·요새 탐지·제작법·텍스처·팩 매니페스트 검사 PASS.
- 전체 `.mcworld`·`.mcaddon`·소스 ZIP·전체 ZIP 구성, CRC·SHA-256, 보존된 v1.6.0 원본 월드 DB 바이트 동일성 검사 PASS.
- 소스 검사 근거: [Ground Fix CI #44175090116](https://github.com/geumyi22/Manhunt-Night/actions/runs/44175090116). 정식 Stable 배포용 GitHub Actions는 `main`에서 동일 검사 및 게시 파일 재다운로드·해시 검증을 다시 수행합니다.

## 알려진 제약 (미검증과 구분)

- 네더 요새 자동 탐지는 **탐사 지역의 자연 위더 스켈레톤과 주변 벽돌에 기반한 위치 추정**이며, 아무도 탐험하지 않은 먼 요새의 정확한 위치를 찾아주는 기능이 아닙니다. 몹 스폰 부족/커스텀 구조/다른 애드온 환경에서 오탐·미탐 가능성이 있습니다.
- 실제 8인 상한 환경의 성능과 FPS·게임별 네트워크는 별도 측정 자료가 없으며, 자동 CI나 2·3인 실기로 대체하지 않습니다.
- 원본 [v1.6.0 Stable QA](history/QA_REPORT_v1.6.0.md)와 기존 실기/측정 결과는 보존합니다. 이번 릴리스의 14/14는 **사용자 직접 보고**라는 증거 수준을 유지합니다.
