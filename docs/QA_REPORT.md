# MANHUNT NIGHT v1.4.0 — QA 보고서

검증일: 2026-11-05 KST · 기준: 사용자 제공 v1.3.0 배포본 (월드 원본 보존)

## 이번 버전 변경
- `게임 설정`을 5개 기능별 탭으로 분리. 기존 설정과 추가 옵션 **20개 신규 토글 + 기존 2개 토글**, 수치 옵션/기존 토글 포함.
- 설정은 로비 또는 종료 상태의 호스트만 수정하고 저장합니다. 다음 경기부터 적용됩니다.
- 추적 ON/OFF, 해금 시간 ON/OFF·0~30분, 나침반 제작 필수 여부, 마지막 이동 좌표, 차원 알림, 헌터 HUD.
- 러너 버프·3회 야생 부활·근접 경보, 월드 경계·요새 힌트·엔드 보상, 수신기·카메라·광선 개별 제어.
- 로비 메뉴 아이템 자동 지급, 시작 지급품 명령어, 접속 종료 자동 일시정지, 기존 팀 피해/인벤 유지/음식/도주 유예.
- 선택 기능 OFF 시 필요 없는 작업 생략. 국지 검사는 5틱에서 10틱, 근접 체크는 5틱에서 20틱 주기로 완화.
- **승패·경기 상태·데이터 보호 등 필수 엔진은 끌 수 없음**.

## 테스트 권장 순서
1. 새 `.mcworld` 가져오기 → `/mh:menu` → 게임 설정 ①~⑤ 모든 설정 토글·저장·재열기.
2. 3~4인 참여 후 추적 OFF, 자동 추적, 수동 나침반 모드를 2~3개 복사 월드에서 확인.
3. 러너 버프·부활 OFF, 헌터 HUD·차원 알림 OFF, 시작 빵 ON/OFF 확인.
4. 카메라/광선 OFF 및 모드 ON 확인, 게임 종료·서버 재시작 후 설정 유지.
5. 오래된 월드는 삭제하지 말고 별도 복사로 시험. 원래 지형으로 되돌리려면 새 월드 가져오기.
