# Manhunt Night v1.7.0 — 외부 월드 호환성 QA

**상태: Pre-release (2026-11-15).** 이 문서는 새로운 호환성 작업에 대한 검증 상태이며, [기존 v1.6.0 Stable QA](history/QA_REPORT_v1.6.0.md)의 실제 2·3인 시험 결과를 변경하거나 재해석하지 않습니다.

## 구현한 변경

- 다른 시드에서 **기존과 동일한 21×21 공중 로비 자동 건축**. 빈 영역 사전 검사·주변 위치/높이 탐색·블록 쓰기 실패 시 작성한 블록만 롤백 시도. 저장된 기존 로비는 재사용하고, 이전 v1.7.0 좌표 전용 로비는 대기 상태에서 건축형으로 전환.
- 새 맵의 시작점에 맞춘 월드 경계(오버월드/네더)
- 기존 맵 외의 고정 네더 요새 좌표 오안내 차단; 실제 X/Z 수동 등록
- 신규 맵의 요새 도착 판정과 기존 40분/헌터 선진입 알림 유지

작업 환경의 연결 PC는 현재 오프라인이므로 이번 버전의 새로운 Minecraft 실기 테스트는 수행했다고 주장하지 않습니다. [추가 실기 QA Issue #12](https://github.com/geumyi22/Manhunt-Night/issues/12)에 남은 항목을 등록했습니다. CI와 모의 이벤트 검사가 성공하더라도 다른 모든 시드/커스텀 월드에서 보장되지 않습니다.

## 알려진 제한

- Bedrock 안정 Script API의 CommandResult는 성공 횟수를 제공하지만 /locate 좌표는 제공하지 않습니다. 다른 시드 요새 안내에는 호스트가 확인한 좌표를 등록해야 합니다.
- 임의의 사용자 제작 요새 벽돌과 실제 자연 요새를 100% 구별할 수 없습니다.
- 원본 전용 시드와 같은 시드를 사용하는 개조 맵은 기존 클래식 로비 모드로 인식될 수 있습니다.
- 로비 영역이 점유됐거나 청크가 읽히지 않는 경우 주변 후보도 실패하면 구조물을 생성하지 않습니다. 중단/청크 오류 뒤의 지형 보호 및 명령어 재시도는 실제 게임에서 추가 확인해야 합니다.
- 특수 제작 월드의 포털, 높이 제한, 외부 애드온 충돌은 해당 월드에서 검증해야 합니다.

검증 결과는 기존 Stable이 아닌 v1.7.0의 실제 빌드 커밋·GitHub Actions 실행 ID에 연결해 추후 갱신합니다.
