# Manhunt Night v1.7.5 Stable

**2026-11-18 사용자 정식 승인 · 신규/변경 기능 실기 14/14 통과 · 자동 회귀 249/249 통과.** 이전 [v1.6.0 Stable](https://github.com/geumyi22/Manhunt-Night/releases/tag/v1.6.0)의 원본 파일과 검증 기록은 보존합니다.

정식 경기 2~8명(러너 1명·헌터 1~7명), 1인 연습 지원. Minecraft Bedrock 26.62 이상 기준, 정식 Script API server 2.11.0/server-ui 2.3.0 사용.

## v1.7.5 변경 사항

- 외부 맵에서 기존과 같은 21×21 파랑/빨강 공중 로비 자동 생성, 빈 영역 탐색·건축물 보호, 실패 시 `/mh:lobbycreate` 재시도.
- **Y≈100 공중 출발 수정:** 안전한 실제 지면·발/머리 공간을 확인해 러너·헌터 시작과 리스폰 지점을 보정합니다. 이전에 잘못 저장된 시작 높이도 새 경기 전 검사합니다. 안전한 지면을 찾지 못하면 인벤토리 초기화 전에 경기 시작 거절.
- 다른 시드 오버월드/네더의 경계를 시작 위치 기준으로 적용.
- 네더 탐험 중 자연 위더 스켈레톤과 요새 벽돌 증거를 감지해 근처의 **추정 위치**를 자동 기록, 기존 40분/헌터 선진입 시 러너에게만 힌트 제공. 호스트 수동 좌표가 우선.
- 추적기 20분 제작법 공개/40분 자동 지급, 32프레임 나침반, 공동 제작, 러너 경고·부활, 헌터 소집서, 신호 수신기, 승패·설정·전적 유지.

## 파일 받기

[v1.7.5 Stable 정식 릴리스](https://github.com/geumyi22/Manhunt-Night/releases/tag/v1.7.5)에서 설치 용도에 따라 선택합니다.

- `Manhunt_Night_v1.7.5.mcworld`: 기존 전용 맨헌트 세계로 새로 플레이
- `Manhunt_Night_v1.7.5.mcaddon`: **다른 월드의 복사본에 적용**
- `Manhunt_Night_Source_v1.7.5.zip`: 소스와 테스트
- `Manhunt_Night_v1.7.5_FullFiles.zip`: 게임·소스·설치/QA 문서 및 무결성 파일 묶음
- `SHA256SUMS.txt`, `Manhunt_Night_v1.7.5_FullFiles.zip.sha256`: 다운로드 무결성 확인

**월드를 먼저 백업하세요.** 맨헌트 경기 시작/초기화는 참가자 인벤토리·장비·경험치를 초기화하며, 채굴한 지형·드래곤 상태는 복구하지 않습니다. 이전 같은 버전의 Preview/RC1을 사용한 경우 팩 중복을 피하고 `/mh:menu`의 `Stable v1.7.5 · 지면 출발 보정` 표시를 확인하세요.

## 검증·제약

**실기:** 사용자가 변경 사항 14/14 통과로 최종 승인했습니다. **자동:** 249/249 회귀와 정식 API 타입/구문/월드 DB 원본 바이트 보존·SHA-256 검사를 수행했습니다. 이는 실제 8인 성능·FPS·게임 네트워크 계측을 의미하지 않습니다. 네더 자동 발견은 탐험 지역의 추정 좌표로, 미탐험 모든 요새의 정확한 위치 검색을 보장하지 않습니다.
