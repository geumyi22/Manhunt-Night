# MANHUNT NIGHT v1.4.0 — Bedrock 26.60

3~4인 베드락 맨헌트(러너 1, 헌터 2~3). 월드에 팩이 포함되어 있으므로 **`.mcworld` 하나만 가져오면 됩니다.**

## 설치/진행
1. 기존 v1.3.0 월드를 백업 및 보존합니다. 새 `.mcworld`를 가져옵니다. 새 월드에 `.mcaddon`을 다시 적용하지 마세요.
2. 친구 3~4명이 접속해 `/mh:menu` → 러너 선택 → **게임 설정**(5개 카테고리) → 시작.
3. 설정은 **로비 또는 경기 종료 화면에서만 관리자가 변경**할 수 있고 저장되며, **다음 경기부터** 적용됩니다.
4. 직접 제작이 ON이면 헌터가 철 4 + 레드스톤 1개로 일반 나침반을 만들어 들고, 해금 시간 이후 추적기로 바꿉니다. 끄면 해금 후 HUD로 자동 추적하며 나침반이 지급되지 않습니다.
5. 게임 중 메뉴 아이템은 제거됩니다. `/mh:menu`로 메뉴를 열 수 있습니다.

## 설정 카테고리 · 개별 ON/OFF

### ① 기본 경기 / 지급품
- 러너 도주 유예: 0~180초 (0이면 OFF)
- 시작 빵: 0~16개 (0이면 OFF)
- 헌터 간 직접 공격 허용 ON/OFF
- 인벤토리 유지 ON/OFF
- 참가자 이탈 시 자동 일시정지 ON/OFF
- 시작 지급품 전체 회수/복구 명령어 ON/OFF
- 로비 메뉴 아이템 자동 지급 ON/OFF (`/mh:item`으로 수동 요청 가능)

### ② 추적 / 헌터 정보
- 러너 추적 시스템 ON/OFF
- 추적 해금 지연 ON/OFF (OFF면 즉시 사용 가능)
- 해금까지 0~30분(5분 간격, 기본 15분)
- 직접 나침반 소지 필수 ON/OFF (OFF면 나침반 없이 자동 HUD)
- 다른 차원으로 떠난 마지막 좌표 추적 ON/OFF
- 러너 차원 이동 채팅 알림 ON/OFF
- 헌터 팀원 위치 HUD ON/OFF

- 유예 시간 중 재생·느린 낙하 효과 ON/OFF

### ⑤ 신호 수신기
- 신호 수신기 기능 ON/OFF
- 헌터 카메라 전환 ON/OFF
- 러너 광선 효과 ON/OFF

**경기 성립을 위한 승패 판정·데이터 보호·역할 구분·메뉴 명령어·필수 상태관리는 OFF 불가입니다.** 위의 옵션은 관리자만 변경하며 소리·표시·지급·버프를 개별 제어합니다. 설정은 월드 동적 속성으로 저장되고 기존 v1.3.x 설정도 자동 이관됩니다.

## 기존 명령어
- `/mh:menu` 메뉴 열기(아이템 불필요)
- `/mh:item` 대기실에서 메뉴 아이템 수동 지급(경기 중 차단)
- `/mh:kitoff` 러너 출발 첫 1분에 전체 시작 빵 회수(기능 ON일 때)
- `/mh:kiton` 회수·보관한 남은 빵 복구(기능 ON일 때)
- `/mh:unstuck` 로비 이동/입력 잠금 복구
- `/mh:admin` 호스트 권한 복구(오퍼레이터/호스트 권한 필요)

## 최적화
- HUD 5틱 주기 유지(추적 표시 반응성)
- 월드 경계 검사 및 녹색 입자 처리 10틱 단위
- 근접 경보 거리 검사 20틱 단위
- 활성 수신기 카메라가 없으면 불필요한 카메라 초기화 생략
- 꺼진 기능은 관련 월드 연산/효과 실행 생략
- 새로운 엔티티/상시 로딩 영역이나 별도 점수판 생성 없음
